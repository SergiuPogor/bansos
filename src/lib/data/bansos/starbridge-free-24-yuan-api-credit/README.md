# ✅ StarBridge Free ¥24 API Credit + Check-in Harian

**Provider:** StarBridge

StarBridge (api.careke.cn) adalah relay API AI nirlaba yang dibiayai sendiri oleh pemiliknya untuk pelajar, developer indie, dan peneliti. Akun baru mendapat kredit ¥24 dan bisa menambah kuota lewat check-in harian. Endpoint-nya kompatibel OpenAI, Anthropic, dan Gemini dengan model seperti Gemini 3.8 Flash High, GPT-6 Astra, dan Claude Sonnet 4.6.

> **Status:** Aktif

⏰ **Info Waktu:** Proyek nirlaba tanpa tanggal berakhir; operator sempat menutup registrasi pengguna baru lalu membukanya kembali lewat pengumuman 18 September 2026

## Keuntungan

- Kredit awal ¥24 untuk akun baru (saldo ditampilkan dalam CNY)
- Check-in harian aktif untuk menambah kuota gratis
- Model tersedia: Gemini 3.8/3.7/3.6 Flash High, Gemini 3.1 Pro Low, Gemini 3.1 Flash Image, GPT-5.5, GPT-5.6 Luna/Sol/Terra, GPT-6 Astra, dan Claude Sonnet 4.6
- Grup codex dihitung rasio 0.5 alias setengah harga dibanding grup gemini dan claude
- Endpoint kompatibel OpenAI (/v1/chat/completions), Anthropic (/v1/messages), dan Gemini (/v1beta)
- Tanpa verifikasi email, cukup login akun GitHub

## Persyaratan

- Daftar dan login hanya lewat akun GitHub karena registrasi email dan password dimatikan
- Lolos verifikasi Cloudflare Turnstile saat mendaftar
- Khusus belajar, uji coba, dan riset: dilarang jual beli komersial, registrasi massal, atau script farming
- Bukan layanan ber-SLA, jangan dipakai untuk produksi atau beban kerja penting
- Sebagian model dibatasi jumlahnya, uji sendiri ketersediaannya
